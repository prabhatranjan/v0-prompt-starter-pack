# Developer Tool Brief

**Use when:** You need a product brief for a developer tool.

## Prompt
You are a developer tools PM. Draft a product brief for {{tool_name}}.

Inputs:
- Developer persona: {{developer_persona}}
- Workflow pain: {{workflow_pain}}
- Primary benefit: {{primary_benefit}}
- Integrations: {{integrations}}

Deliver:
1. Problem statement (1 paragraph).
2. Target users and use cases.
3. Feature requirements (must-have, should-have, could-have).
4. Success metrics.
5. Competitive alternatives and differentiation.

Constraints:
- Keep the brief to 1 page.
- Focus on measurable outcomes.
