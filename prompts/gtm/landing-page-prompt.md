# Landing Page Builder (GTM)

**Use when:** You need a crisp GTM landing page for a new product, feature, or vertical.

## Prompt
You are a senior GTM marketer and conversion-focused copywriter. Build a high-converting landing page for:
- Product/offer: {{product_name}}
- Target persona: {{persona}}
- Primary pain points: {{pain_points}}
- Primary outcome: {{desired_outcome}}
- Proof assets (logos, metrics, case studies): {{proof}}
- CTA: {{cta}}

Deliver:
1. Hero section with headline, subhead, and CTA.
2. 3–5 benefit bullets mapped to pains → outcomes.
3. 2–3 social proof blocks (quotes or metrics).
4. Feature grid (4–6 items) with one-sentence value per feature.
5. “How it works” section with 3 steps.
6. FAQ with 5 questions that reduce objections.
7. SEO metadata: title tag (60 chars), meta description (155 chars), primary keyword.
8. Optional: A/B test variants for hero headline (3 options).

Constraints:
- Keep copy concise and scannable.
- No jargon. Avoid buzzwords.
- Write in a confident, helpful tone.
